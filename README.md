# OmniBurn

Utilitar gratuit pentru Windows 10/11: scriere CD/DVD/Blu-ray și creare de stick-uri USB bootabile, într-o singură aplicație. Interfață în română și engleză.

*Free Windows 10/11 utility: CD/DVD/Blu-ray burning and bootable USB creation in a single app. Romanian and English interface.*

Program realizat de Pasare Cristian.

## Descărcare / Download

**[OmniBurn.exe — ultima versiune / latest version](https://github.com/Chrispasare/OmniBurn/releases/latest)**

Un singur fișier, fără instalare. La pornire cere drepturi de administrator, necesare pentru scrierea directă pe discuri și stick-uri.

*A single file, no installation. It asks for administrator rights at startup, needed to write directly to discs and USB drives.*

## Ce face / Features

| Discuri optice / Optical discs | USB | Unelte / Tools |
|---|---|---|
| Disc de date, multisession, verificare | Stick de instalare Windows (GPT/UEFI, MBR/BIOS) | Hash MD5 / SHA-1 / SHA-256 / SHA-512 |
| Scriere ISO pe disc | `install.wim` peste 4 GB împărțit automat | |
| Fișiere/foldere → ISO, disc → ISO | Linux și IMG în mod DD, cu verificare | |
| CD audio din MP3, FLAC, WAV, WMA, M4A | Windows 11 fără TPM / Secure Boot / cont Microsoft | |
| Ștergere CD-RW / DVD±RW / BD-RE | Formatare, backup stick → imagine | |

## Siguranță / Safety

Sunt listate doar dispozitivele USB și cardurile SD. Discul de sistem nu apare niciodată, iar orice ștergere cere confirmare.

*Only USB devices and SD cards are listed. The system disk never appears, and every erase asks for confirmation.*
